# 飴玉工房 固定ページ制作ルール

## アプリ情報

- 日本語名：飴玉工房
- URLスラッグ：`amedama-kobo`

## 言語

飴玉工房のWebページは日本語版のみ作成します。

英語ページおよび言語切替機能は作成しないでください。

## URL構成

- `/amedama-kobo/`
- `/amedama-kobo/privacy-policy/`
- `/amedama-kobo/support/`

`/amedama-kobo/` のアプリ紹介トップページは後から制作します。

現時点では、プライバシーポリシーとサポートページを優先します。

## デザイン

飴玉工房アプリの画面デザインを基準に、やさしく温かみがあり、少しレトロな工房・手仕事を感じるデザインにします。

fuji-sohoサイト内の固定ページとしての統一感も保ち、特にプライバシーポリシー、サポートページでは装飾より可読性を優先してください。

- ベース背景：`#F4F1E8`
- 本文カード：`#F7F6F1`
- 本文・タイトル：`#343A38`
- 補助文字：`#8F8D87`
- 赤：`#BE625E`
- 青：`#527F8F`
- 緑：`#657F5C`
- ベージュ：`#B9B09D`
- 黄・飴色：`#C99D3F`
- 枠線：`#D8D7D0`

赤・青・緑・ベージュはアプリ画面の主要な識別色として扱い、黄・飴色はアクセントとして使用できます。

色は提供されたアプリのスクリーンショットを基準にWeb向けに整理したものです。アプリの世界観から大きく外れる色を独自に追加しないでください。

## フォント

- 日本語：`はれのそら明朝`
- アプリ本体で使用しているフォントであり、Webページでも飴玉工房の主要フォントとして使用する
- `はれのそら明朝` は IPA Font License Agreement v1.0 に準拠して配布されている
- Webフォントとして配信する場合は、配布元の利用条件および IPA Font License Agreement v1.0 の再配布条件を遵守する
- ライセンス表示・ライセンス文書など、再配布に必要な対応を省略しない
- フォントファイルの形式変換、サブセット化、改変を行う場合は、事前にユーザーへ確認する

## ロゴ・画像

現時点では飴玉工房の専用ロゴはありません。

今後ロゴを制作するか、アプリ画面で使用している「飴玉工房」の文字表現を採用する予定です。

Codex側で正式なロゴを独自に作成・決定しないでください。

Webページで使用するアプリ画像が必要な場合は、ユーザーがスクリーンショット等を用意します。提供されていない画像を正式素材として独自に決定しないでください。

飴玉、瓶、工房をイメージしたアプリ固有の画像や装飾は、将来制作するアプリトップページでは比較的大きく使用できます。

プライバシーポリシー、サポートページでは、ページ上部や見出し周辺のワンポイントとして控えめに使用し、本文背景全面には使用しないでください。

## プライバシーに関する既知の仕様

現時点の飴玉工房は以下の仕様です。

- 飴玉に関するデータは利用者の端末内にのみ保存する
- 予定データは利用者の端末内にのみ保存する
- 開発者のサーバーへこれらのデータを送信しない
- アカウント登録なし
- ログイン機能なし
- 広告なし
- Analyticsなし
- 広告トラッキングなし
- iCloud / CloudKitによる同期は予定していない

これらは実装・ページ構成を判断するための仕様情報です。

**この情報を元にCodexがプライバシーポリシー本文を作成してはいけません。**

プライバシーポリシー本文は、ユーザーから提供される確定済み文章をそのまま使用してください。

本文を独自に作成、補完、リライト、校正しないでください。変更が必要だと判断した場合は、変更せずユーザーへ確認してください。

## サポート・お問い合わせ

飴玉工房のサポートページは、App StoreのサポートURLとして使用する予定です。

問い合わせ方法は現時点では確定していません。

候補は以下です。

- fuji-sohoサイトの既存お問い合わせフォームへ誘導する
- Contact Form 7を使用して飴玉工房用の問い合わせフォームを作成する

ユーザーから明示的な指示があるまで、新しい問い合わせフォームを独自に作成しないでください。

## 運営者表記

プライバシーポリシー等の運営者名は、ユーザー本人の氏名を使用します。

氏名は本文作成時にユーザーから提供される情報を使用し、Codex側で推測しないでください。

## 制定日・改定日

制定日および改定日は、プライバシーポリシー本文の確定時にユーザーが指定します。

Codex側で日付を独自に決定しないでください。

## 実装上の分離

- ルートクラス：`.app-page--amedama-kobo`
- 専用画像：既存構成を確認して飴玉工房専用ディレクトリに保存
- 専用CSSは飴玉工房のページだけで読み込む
- 飴玉工房固有の色、画像、文章を他のアプリへ流用しない
- ミミの冒険固有の色、画像、文章、広告・Analytics等の仕様を飴玉工房へ流用しない
